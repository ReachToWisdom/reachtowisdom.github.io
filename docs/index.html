⌂LAND BROWSER

매물 검색과 비교를
한 화면에서

네이버 부동산 지도를 보며 매물을 찾고, 관심 매물과 비교 구성을 프로젝트별로 저장하는 Windows 앱입니다.

Windows 설치 파일 다운로드 포터블 ZIP 다운로드

Windows 10/11 · x64 · 버전 0.1.0 · SHA-256 체크섬

지도 기반 검색

서울·경기·인천의 매매·전세 조건을 고르고 지도에서 매물 위치를 살펴보세요.

프로젝트에 저장

검색 조건, 보관 매물, 메모, 비교 목록을 이름 붙인 프로젝트에 보관합니다.

나란히 비교

매물 상세 정보와 제공되는 평면도·사진을 비교 화면에서 확인할 수 있습니다.

설치 방법

  1. 설치 파일을 내려받아 실행합니다. 사용자 계정에 설치되며 관리자 권한은 필요하지 않습니다.
  2. 시작 메뉴 바로가기가 생성됩니다. 설치 화면에서 바탕화면 바로가기도 선택할 수 있습니다.
  3. Microsoft WebView2 Runtime이 없는 PC에는 설치 프로그램이 런타임을 준비합니다.
  4. 작업 표시줄 고정은 시작 메뉴에서 Land Browser를 찾아 마우스 오른쪽 버튼을 누른 뒤 작업 표시줄에 고정을 선택하세요.

데이터와 매물 조회

프로젝트와 사용자 데이터는 PC에 저장되며 앱을 업데이트해도 유지됩니다. 현재 매물 조회 어댑터는 네이버의 공개 문서 API가 아닌 내부 조회 경로를 사용하므로, 허가된 경우에만 이용해야 합니다. 조회 제공 방식과 정책은 바뀔 수 있습니다. 자세한 내용은 앱에 포함된 사용 안내와 제3자 고지를 확인하세요.
